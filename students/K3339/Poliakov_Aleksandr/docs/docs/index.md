## Описание проекта

Серверное приложение на FastAPI для управления личными финансами. Позволяет пользователям вести учёт счетов, транзакций, категорий расходов и доходов, а также планировать бюджет.

## Стек

- **FastAPI** — веб-фреймворк
- **SQLModel** — ORM (поверх SQLAlchemy)
- **PostgreSQL** — база данных
- **Alembic** — миграции
- **python-jose** — JWT-токены
- **passlib[bcrypt]** — хэширование паролей

## Модель данных

| Таблица | Описание |
|---------|----------|
| `User` | Пользователь системы |
| `Account` | Счёт (карта, кошелёк и т.д.) |
| `Category` | Категория транзакции (еда, транспорт...) |
| `Transaction` | Доход или расход |
| `TransactionCategory` | Связь транзакции с категориями (M:M) |
| `Budget` | Лимит бюджета по категории на месяц |
